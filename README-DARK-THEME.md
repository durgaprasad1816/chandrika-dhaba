# Chandrika Dhaba & Restaurant — Premium Dark Theme

This package applies a premium charcoal-black, deep-red and gold visual theme inspired by the reference supplied by the restaurant owner.

## Branding and typography
- Brand text: **Chandrika Dhaba & Restaurant**
- Display type: bundled **Yatra One** for the restaurant name and display headings
- Body type: bundled **Poppins**
- Telugu text: bundled **Noto Sans Telugu**

## Menu layout
- Mixed Biryani is shown first as the Dhaba Special hero.
- Menu categories remain stacked vertically.
- Items within each category use horizontal scrolling cards.
- Existing details popup, menu filters, waiter login and manager features are retained.
- Photos use bundled food imagery and category fallbacks when no item-specific image has been set.

## Run on Windows
1. Extract this ZIP.
2. Open the `chandrika-dhaba` folder in PowerShell.
3. Run `run.bat` or follow the main `README.md` instructions.
4. Open `http://localhost:8080`.

Before replacing an existing installation, back up your `data` folder. The JAR in `dist/` has its bundled HTML/CSS updated to the dark theme.
