# Changes - 15 Nov 2026

## 1. Green / gold theme + new welcome screen
* Whole app (customer menu, waiter panel, manager dashboard, login) re-coloured to the deep-green, gold and terracotta look.
* New opening animation: green centre band, logo + gold flourishes, a round dish photo, a slowly rotating gold mandala behind it,
  and "WELCOME TO CHANDRIKA DHABA & RESTAURANT" in **Cinzel** (closest free match to the lettering in your sample image).
  The restaurant name in the title comes from Settings -> Restaurant name.
* **Settings -> Welcome screen picture**: choose a new picture or go back to the default.
  Files: `web/css/splash.css`, `web/css/theme-green.css`, `web/index.html`, `web/img/welcome-dish.jpg`, `web/fonts/cinzel-*.woff2`.

## 2. Order numbers 1, 2, 3 ... (restart every day)
* The server gives each confirmed order the next number of the day. Every waiter's panel shows **"Next order: N"** and
  **"Order No. N · date"** in the New order sheet, and updates within ~1.5 seconds when another waiter confirms an order.
* The kitchen queue and the order lists show the same numbers. Old orders keep working.

## 3. Google sign-in + Google Drive (Settings -> Google account & Drive)
* Manager logs in with username/password as before, then connects a Gmail account in Settings.
* **Invoices**: every paid bill is saved as a PDF (+ the payment photo) into the Drive folder you paste in Settings.
  "Create a new sub-folder for each day" makes `2026-11-15`, `2026-11-16` ... automatically. Change the folder link any day.
  If Drive is offline the sale is not blocked: invoices wait in a queue and retry every 30 seconds.
* **Pictures**: dish photos, waiter photos / Aadhaar pictures and the welcome picture are stored in Drive
  (folder "Chandrika Dhaba - Data"). A disposable copy is kept in `data/cache` for speed. If Google is not connected,
  everything works as before on this computer; "Move existing pictures to Drive" moves old ones later.
* Setup steps: see `GOOGLE-DRIVE-SETUP.md`.

## 4. Update 16 Nov - "old data comes back" fix
* The data folder is now always the `data` folder of the project (next to `dist/`), no matter which folder the terminal is in.
  Before, starting the jar from another folder silently created/used a different data folder. The start-up text now prints
  `Data folder : <full path>` - check it is the same every time.
* Only one copy of the app can use a data folder. A second window is refused with a clear message (two copies overwrote each
  other's saves).
* Order numbers restart at 1 at 12:00 am India time (checked).

## 5. Data no longer reverts on Render free plan
- Automatic Drive backup/restore of store.json, bills.jsonl, collections.jsonl (+ picture index), see GOOGLE-DRIVE-SETUP.md.
- New env vars: DHABA_GOOGLE_CLIENT_ID / DHABA_GOOGLE_CLIENT_SECRET / DHABA_GOOGLE_REFRESH_TOKEN.
- Settings: "Back up now" and "Show key for Render".
