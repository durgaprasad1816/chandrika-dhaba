# UI update — 2026-10-31

Changes in this update:
- Category left/right arrows are overlaid inside each horizontal menu section; they no longer reserve separate side columns.
- Quantity control retains minus/plus and adds an explicit remove (×) action to clear an item from the cart.
- Waiter cart is presented as a compact floating cart icon at the bottom-right.
- Waiter table panel includes a selector for the waiter's assigned tables/beds. Switching location updates the current QR table URL, reloads its order panel, and restores that table's locally saved draft cart.
- Draft carts are saved per waiter and per table in that browser's local storage.

Validation:
- `node --check` passed for customer.js, manager.js, and qr.js.
- Full Maven/browser workflow validation should be run on the target Windows machine before restaurant use.
